---
title: Secrets
description: How Oxygen stores API keys, model keys, and integration tokens
type: concept
audience: admin
tier: standard
---

Secrets are stored per workspace and are scoped to the projects inside
that workspace. The Secrets panel lives at **Settings → Workspace → Secrets**.

Oxygen automatically detects which secrets each project needs (LLM API
keys, database credentials, integration tokens) and surfaces a warning
on the home page when one is missing.
