---
title: Secrets
description: How Oxygen stores API keys, model keys, and integration tokens
type: concept
audience: admin
tier: standard
---

Secrets belong to your organization: its apps, agents and databases read
them. The Secrets panel lives at **Settings → Organization → Secrets**, with
two tabs: **Shared**, for a value stored once and shared with the apps you
choose, and **One app**, for a value a single app keeps for itself.

A secret that holds an Oxygen API token — the way a custom app that calls the
Oxygen API keeps one — can be created in place: see
[A token for a custom app](/guide/manage/api-keys#a-token-for-a-custom-app).

Oxygen automatically detects which secrets each project needs (LLM API
keys, database credentials, integration tokens) and surfaces a warning
on the home page when one is missing.
