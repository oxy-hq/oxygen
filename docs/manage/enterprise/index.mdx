Enterprise is a license tier inside Oxygen Cloud. Standard Cloud unlocks
the full product surface — Agents, Automations, the Semantic
Model, MCP, agent testing — for any workspace. Enterprise adds the
features below for organizations with compliance, identity, or
support requirements.

[Contact sales →](https://oxygen-hq.com/contact)

## Standard vs Enterprise

| Feature | Standard Cloud | Enterprise |
| --- | --- | --- |
| Agents, Automations, Semantic Model | ✅ | ✅ |
| MCP server, Builder agent, agent testing | ✅ | ✅ |
| Magic link auth, Google OAuth | ✅ | ✅ |
| Okta / SAML / Azure AD SSO | — | ✅ |
| Row-level policy controls | — | ✅ |
| Audit logs | — | ✅ |
| Domo connector | — | ✅ |
| Snowflake secure access | — | ✅ |
| SLA-backed support | — | ✅ |
| Custom onboarding | — | ✅ |

Legend: ✅ included · — not available

<Note>
Enterprise pages elsewhere in the docs are tagged with a small purple
**Enterprise** badge next to the heading. The page itself is still
readable by every workspace — the badge signals that activating the
feature requires the Enterprise tier.
</Note>
